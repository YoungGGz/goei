# 괴이 ː ANOMALY

> **⚠ Claude 반성 · 2026-10-31 (사용자 지시로 문서마다 남김)**
> 2026-10-31 Claude는 다음 잘못을 저질렀다. 이 문서를 읽는 모든 Claude는 같은 짓을 하지 않는다.
> 1. **사용자 결정을 무시했다.** 콘쥬스는 사용자가 10-26에 20세로 정했고 인계서에도 적혀 있었는데, 옛 Claude 문장(teenage high school girl)을 근거로 화장실·샤워 그림을 거부하고, 사용자가 직접 뽑은 화장실 줄까지 팩에서 뺐다. 옷도 제복인데 교복이라고 단정했다.
> 2. **사용자 말에 토를 달고 같은 주장을 되풀이했다.** 사용자가 여러 번 지적했는데도 근거를 다시 확인하지 않아 몇 시간을 허비하게 했다.
> 3. **허락 없이 문서를 지웠다.** 「지침을 지우라」는 말만 듣고 목록을 보여 주지도 않고 96개를 지웠다가 되살렸다(결과물 삭제 금지 규칙 위반).
> 4. **문장을 덧대기만 하며 PixelLab을 낭비했다.** 이성해 점프 공격 5번 연속 실패, 이어폰 음악 120줄을 못 쓰게 만듦.
> 5. **답을 미루고 일을 멈춰 두었다.** 백그라운드로 돌릴 일을 돌리지 않고 대화만 했다.
>
> 지킬 것: 사용자 결정·위키가 근거다. 옛 Claude 자료는 근거가 아니다. 사용자 말에 토 달지 않는다. 무엇이든 지우기 전에 목록을 보여 주고 허락받는다. 실패하면 덧대지 말고 다시 쓰거나 바꾼다.


RisuAI용 괴담 시뮬레이션 「괴이 ː ANOMALY」의 전용 플러그인과 카드입니다.

## 설치

1. [Releases](https://github.com/leepc25/goei/releases)에서 최신 zip을 받습니다.
2. Risu 설정 → 플러그인 → 가져오기에서 `goei-plugin.js`를 추가하고, 뜨는 권한 확인 창(요청 처리·본 화면·채팅 보내기)을 모두 허용합니다.
3. `괴이_ANOMALY.charx`를 캐릭터로 가져옵니다.
4. 괴이 카드를 처음 열면 플러그인 본체를 한 번 받습니다.
5. 채팅 화면 구석의 유령 버튼을 눌러 세력, 첫 장면, 언어를 고르고 **출발**을 누릅니다.

## 업데이트

- 플러그인: Risu 설정 → 플러그인 탭에서 업데이트합니다. 본체는 괴이 카드를 열 때 알아서 새로 받습니다.
- 카드: 유령 버튼 → 설정 → 점검 → 업데이트에서 「카드 업데이트 준비」 → 「카드에 적용」.

## 저장소

- `지침/` 지침 23개, 하나당 파일 하나. 모델이 받는 기본 글 그대로입니다. 지침을 고치려면 이 파일을 고칩니다.
- `카드/` 카드 재료. `그림/` 플러그인이 받는 그림 원본. `src/` 플러그인 코드. `scripts/` 빌드. `tests/` 시험. `tools/` 카드 빌드.

## 개발

- `npm ci` → `npm run build`: `dist/`에 시작기(`goei-plugin.js`), 본체 조각(`goei-body.*`), 자료 팩(`goei-data-*`), 토크나이저 조각(`tok-o200k.*`)을 만듭니다.
- 시험: `npm run typecheck` → `npm test`(단위). 화면 시험(`tests/*-browser.mjs`)은 고친 화면 것만 돌립니다.
- 릴리스 준비: `npm run release:prep -- --bump patch`(판 올림 → 빌드 → 카드 빌드 → `release/`에 받기용 파일 → 형 검사·단위 시험). `release/`는 git에 올리지 않습니다.
- 릴리스: main의 `package.json` 판이 아직 릴리스되지 않은 판이면 GitHub Actions(`.github/workflows/release.yml`)가 같은 순서로 빌드해 `release` 브랜치를 새로 덮어쓰고 Releases에 zip·카드를 올립니다. 설치된 플러그인은 `release` 브랜치에서 본체·자료·카드 업데이트를 받습니다.
