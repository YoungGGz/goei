# 본편을 다시 굴린 뒤 감정 없이 맞교환 주문이 확정됨

v0.21.32 (b7c9264), PC Chromium, 실제 플러그인 번들과 모의 Risu 호스트에서 확인했다.

1. ‘행운의 무전기’를 ‘다음 방송 시연 참여’로 주문한다.
2. 본편 응답을 다시 굴린 상태로 바꿔 이전 주문과 상자가 사라진 것을 확인한다.
3. 같은 상품에 전화해 ‘물건 맞교환’을 고른다. 어떤 물건도 내밀거나 감정받지 않는다.
4. 화면의 ‘상담원 조건’에 이전 주문의 ‘다음 방송 시연 참여’가 보이고 ‘이 조건으로 주문’ 버튼이 활성화된다.
5. 버튼을 누르면 새 응답 기준으로 pay=barter, n=1, how=다음 방송 시연 참여인 주문과 미개봉 상자가 저장된다. 원래 소지품인 낡은 손전등도 남아 있다.

기대 동작은 감정 전 주문 버튼 비활성이다(tests/homeshop-edge-browser.mjs 54행). 주문 성공 시 통화 상태에 최종 조건을 복사하고(src/ui/homeshop.ts 603행), 같은 상품의 맞교환에 그 통화 조건을 재사용한다(414행). 재현기는 위 기존 시험의 모의 다시 굴리기 방식을 사용한다. 저장소 루트에서 이 폴더의 run.mjs를 Node로 실행하면 실제 주문 저장 여부를 확인하고 결함을 재현한 경우 종료 코드 1을 반환한다.

같은 판의 기존 스티커 시험도 일반 PC와 큰 PC에서 기본 들추기 뒤 감지된 글자 수가 0/25로 실패했다. 일반 PC 스크린샷에서도 아래쪽 빈 영역만 드러났다. 밑글은 왼쪽 위부터 고정한다는 요구가 있으므로 모든 기본 들추기에서 한 글자 이상을 보여야 하는지는 별도 판단 사항이다.
