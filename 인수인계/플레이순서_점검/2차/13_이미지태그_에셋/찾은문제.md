## 문제

### 1. 보조 모델 방식: 상점 표식이 보조 요청의 본문 단락으로 감 (재현)
- 누른 순서: 이미지 → 모델 「보조 모델」(첫 턴 뒤) → 상점 표식이 붙은 응답을 받음 (B02: 상태창 있음 / B14: 상태창 없음).
- 기대: 플러그인 표식은 보조 모델에 안 감. 근거: 지침 `상점.txt:151` 은 표식을 「상태창 줄 바로 앞」에 쓰라고 하고, 보조 요청은 상태창 줄(`[▣|`)부터 뒤를 떼어 내는데(`src/core/asset.ts:87-89`) 상점 표식은 그 앞이라 남는다. 같은 함수가 생각 칸·주석·상태창·완성 표식(`stripReadyTags`, `src/host/asset.ts:48`)은 빼는데 상점 표식만 안 뺌.
- 실제: `[5] [shop: 관리국 매점|]` 가 번호 붙은 단락으로 실림 (`out/단계B02_첫응답_보충요청.txt` Narrative 칸, `out/단계B14_상태창없음_상점표식.txt` 의 `[2] [shop: …]`).
- 증상: 저장 본문은 맞게 돌아오지만(표식 하나, 끝에) 상점이 있는 턴마다 내부 표식이 보조 모델에 단락 하나로 가고, 모델이 그 단락에 태그를 달면 그림이 표식 자리(본문 끝)에 붙는다.

### 2. 보조 모델 방식: 보충이 도는 중에 다시 굴리거나 다음 응답이 오면 새 응답에 태그가 영영 안 붙음 (재현)
- 누른 순서: 보조 모델 방식에서 응답 A 를 받음 → 보충 답이 오기 전에 다시 굴리기(B10) / 다음 메시지를 보내 응답 B 를 받음(B15).
- 기대: 새 응답도 보통 다시 굴리기(B11: 1회 보충, 태그 붙음)처럼 태그를 받는다. 근거: `src/host/asset.ts:59-61` 은 「작업 중에 메시지가 바뀌었거나 새 메시지가 붙었으면 (옛 답을) 버린다」 — 옛 답만 버리게 되어 있고, 새 응답을 건너뛰라는 결정은 없음.
- 실제: 새 응답의 리스너는 `running` 이라 바로 돌아가고(`src/host/asset.ts:27`), 먼저 돌던 작업은 메시지가 바뀌어 저장을 버림(`:61`). 결과 두 응답 모두 태그 0개, 보조 호출 1회. 「최근 보충」 메모는 그 앞 실패 이유(`rate limit 429`)가 그대로 남음 (`out/단계B10_늦은답_그새다시굴림.txt`, `out/단계B15_겹친응답_두번째.txt`).
- 증상: 응답이 뜨자마자 다시 굴리거나 빨리 다음 말을 보내면 그 응답엔 그림이 안 뜨고, 설정 탭엔 엉뚱한 옛 이유가 보인다.

## 물을 것

### Q1. 출발 직후(첫 전송 전) 설정 창의 이미지 설정이 이 채팅에 안 들어감
- 누른 순서: 시작 화면 → 출발(첫 장면이 뜸, 아직 안 보냄) → 설정 → 이미지 → 「보조 모델」(B01) / 폰에서 「사용 OFF」(P01) → 첫 전송.
- 실제: 그 상태는 시작 패널(staged)이라 설정 창이 「새 채팅 기본값 (시작 전)」 범위로 열림(`src/ui/app.ts:1107-1109`). 값은 `prefs.basic` 에만 적히고 이 채팅 변수는 출발 때 값(`main`·`1`) 그대로라 첫 요청에 메인 이미지 지침이 그대로 감 (`out/결과-B.json` B01, `out/결과-P.json` P01).
- 화면엔 범위 이름이 보이지만, 출발을 누른 뒤의 플레이어는 「이 채팅」을 바꾼 것으로 여길 수 있다. 이 상태에서 이 채팅 값을 바꾸게 할지 사용자 결정이 없음.

### Q2. 보조 답이 꼴이 틀렸을 때 메모가 「붙일 이미지가 없었어요」
- B07: 모델이 JSON 대신 글을 돌려주면 `[]` 와 똑같이 「이번 응답에는 붙일 이미지가 없었어요.」(`src/host/asset.ts:52-54`, `parsePatches` 가 빈 목록). 빈 답은 「모델이 빈 응답을 보냈어요」로 따로 나옴. 꼴 틀림을 실패로 따로 알릴지 근거 없음.

## 확인했고 문제 없던 것 (요약)
- 메인 모델: 첫 요청부터 이미지 지침이 맨 끝 한 번, 명부 55명·표정 42종(카드 에셋에 55×42 다 있음), `{{user}}` 가 페르소나 이름으로 풀림. 따옴표 꼴·밑줄 표정 태그는 그림 칸, 세트 밖 표정·없는 이름은 칸 없이 태그만 지움. 요청 속 태그는 끝 6개 메시지만(표시 범위와 같음). 끔 → 지침 없음·태그 전부 지움·칸 숨김, 켬 → 되돌아옴. 주인공 이미지 켬 → 금지 줄 빠지고 페르소나가 명단에, 페르소나 태그는 유저 사진. 장면 인물만 → 최근 대화 인물 + 주인공. 새로고침 뒤에도 그림 칸.
- 보조 모델: 본문에 나온 사람만 명단·별칭(한글 이름), 생각 칸·주석·상태창·상황판 태그는 빠짐, 태그는 그 단락 바로 뒤, 생각 칸·주석·상태창 그대로. 한도(캐릭터당 2) 넘는 것·세트 밖 표정·명단 밖·범위 밖 줄 버림, 밑줄 표정 고침. 빈 답·실패는 본문 그대로·이유 메모(설정 탭에 보임). 명단 인물 없으면 호출 없음. 응답 속 옛 태그는 빼고 새로. 다음 턴 본편엔 태그·지침 없음. 새로고침만으로 호출 없음.
- 폰: 첫 턴 뒤 이미지 페이지 단추로 끔/켬·그림 칸 같음.
- 괴담넷 `[사진:이름]`: 요청 사진 목록에 최근 본문에 나온 인물만(사용자 11-14), `[사진:잼트리_smile]`·영문명·밑줄 표정·목록 밖이어도 명부 인물이면 그림, 모르는 이름은 사진 설명 틀(표정 꼬리 뗌). 괴담톡은 사용자 11-12 결정대로 그리지 않음(코드만 확인).
- 사진 팩 계획: 지문 바뀐 것만 바꿈·새 것 받음·새 카드에서 뺀 카드 사진만 지움·사용자 사진 그대로·같은 판이면 0.
