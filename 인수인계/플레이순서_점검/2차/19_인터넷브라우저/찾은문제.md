## 문제 1 (보통, 재현) 카드로 연 단독 창을 닫은 뒤 PC 메뉴 ‹ 를 누를 때마다 우주몰 탭이 하나씩 새로 생기고 저장됨

- 누른 순서: 인터넷에서 괴담넷 → 위키 → 창 닫기 → 채팅 카드 `[shop: 우주 쇼핑몰|@web:cos]` 「접속하기」(단독 창) → 닫기 → 창 열기(인터넷) → 왼쪽 아래 ‹ 네 번 (단계61).
- 기대값: 단독 창에서 본 사이트는 상황판 인터넷에 남지 않음, 뒤로 가기로 탭이 늘지 않음. 근거: 사용자 11-20 「카드로 본 망상홈쇼핑이 상황판 인터넷 창에 남아 있다」(app.ts soloBack 주석), 단독 창은 「인터넷 창을 통째로 띄우지 않는다」.
- 실제값: 닫은 직후 탭은 전과 같음(통과). 그러나 ‹ 1번째에 「★우주 쇼핑몰★」 탭이 새로 생기고, 누를 때마다 하나씩 늘어 탭 5개(위키 + 우주몰 4). 2초 뒤 `$br_tabs` = `["wk","cos","cos","cos","cos"]` 로 저장 — 새로고침해도 남음.
- 증상: 뒤로 가기를 누르면 엉뚱한 쇼핑몰 탭이 계속 열리고 쌓인다. 폰 쓸어 뒤로도 같은 함수(navStep)라 같은 일이 생김(코드로 확인, 폰으로는 안 돌림).
- 까닭: 단독 창을 닫을 때 `endSolo` 가 탭을 JSON 으로 되살려(`restoreTabs`) 탭 id 가 모두 새로 매겨지는데, 창 전역 기록 `navHist` 는 비우지 않아 옛 탭 id(단독 창 때 기록 포함)를 그대로 가짐. `navStep` 은 기록의 탭 id 가 없으면 `newTab()` 하고 그 사이트를 띄움.
- 근거: `src/ui/app.ts:179-185`(endSolo), `:1815`(단독 창에서도 navHist.record), `:1930-1935`(없는 탭이면 newTab), `src/ui/browser.ts:174-189`(restoreTabs 가 id 새로 매김). `out/단계61_갈래_카드단독창_뒤_전역뒤로.txt`, `out/상태61.json`.

## 문제 2 (보통, 재현) 폰에서 쓸어 뒤로 가면 다른 탭으로 건너감

- 누른 순서: 폰 서랍 괴담넷 → 탭 수 단추 → 「새 탭」 → 서랍 괴이위키 → 문서 → 오른쪽으로 세 번 쓸기 (단계43).
- 기대값: 쓸기 1·2 는 이 탭의 대문·새 탭 화면, 3 은 이 탭 처음이라 다른 탭으로 안 감. 근거: 사용자 11-10 「탭별로 움직여야 한다」(app.ts 346 주석 — PC 마우스 제스처 ←→ 는 이 말대로 탭 기록 `br-back`·`br-fwd` 만 씀). 폰에는 주소줄 ‹ › 가 없어(PC 전용) 쓸기가 유일한 뒤로.
- 실제값: 1·2 는 맞음. 3번째 쓸기에 지금 탭이 첫 탭(괴담넷)으로 바뀜(`cur 0`, `br-p-gn`).
- 증상: 폰에서 새 탭을 열고 뒤로 쓸다 보면 갑자기 앞 탭으로 넘어간다. PC 는 같은 자리에서 멈춘다(단계04 통과).
- 근거: `src/ui/app.ts:1813` 쓸기는 `navStep`(창 전역 기록)만 부르고, `:346-356` 의 인터넷 분기(탭 기록)는 마우스 제스처에만 있음. `:1930-1933` 기록의 탭으로 `br.cur` 를 바꿈. `out/단계43_폰_쓸어서_뒤로.txt`. 폴드 펼친 PC 배치(isFoldPc)도 쓸기를 받으므로 같은 길(코드만 봄).

## 물을 것 (기대값 근거 없음)

- Q1. PC 에는 왼쪽 메뉴 ‹ › (창 전역 기록)과 주소줄 ‹ › (탭 기록)가 둘 다 있다. 인터넷에서 메뉴 ‹ 로 새 탭 화면에 돌아오면 그 탭 기록 끝에 새 칸이 붙어, 주소줄 › 로 방금 보던 위키에 다시 못 간다(단계62: `back true, fwd false`). 인터넷 안에서 메뉴 ‹ › 도 탭 기록만 따라야 하는지(마우스 제스처처럼) 정한 말이 없다.
- Q2. 폰 쓸기에서 탭의 첫 화면에서 더 뒤로 쓸면 상황판 등 인터넷 밖 화면으로 가는 것이 맞는지(문제 2 를 고칠 때 같이 정할 것).

## 확인만 한 것 (문제 아님)

- 관리국: 즐겨찾기·새 탭·폰 서랍에 포인트몰 없음, 백일몽이면 있음(01·41·63). 망상홈쇼핑은 「인터넷에 상시 노출」 켬일 때만 즐겨찾기에(65, 기본은 없음).
- 소속이 바뀐 뒤에도 남은 포인트몰 탭(저장 탭·닫은 탭 ㄱ 되살리기)이 포인트몰 화면을 그대로 보임(64·68). 03 점검 문제3 과 같은 뿌리(`bmHtml` 에 소속 확인 없음)라 따로 올리지 않음 — 03 문제3 에 「닫은 탭 다시 열기로도 열림」만 덧붙이면 됨.
- 채팅마다 탭이 따로 저장·복원됨(66). 깨진 `$br_tabs` 는 빈 새 탭 하나로(67). 인터넷 밖에서 폰 서랍으로 이미 열린 사이트를 고르면 그 탭으로 감(70).
- 로그인·로그아웃·빈 닉 엔터·지난 닉 미리 채움 모두 정한 대로(10). 게시판 닉 `$gn_nick` 이 로그인과 같이 바뀌는 것은 boards.ts 「닉네임은 인터넷 로그인 하나」대로.
- 본편 요청에 `$br_*`·탭 상태 JSON 없음(12).
