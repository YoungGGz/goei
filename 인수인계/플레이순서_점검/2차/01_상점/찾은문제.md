## 확인만 한 것 (문제 아님)

- 첫 진열: 가게 로어북·상태창(잔고 칸 없음)·FIRST·희귀/특가 규칙, 진열 6개(희귀·특가·대가·원+대가)를 꼴대로 받고 화면 구획에 맞게 보임.
- 문의: 진열 줄이 화면 값 그대로(대가·특가·희귀), 마지막 줄이 방금 한 말, 깎기 수락(▾·원래 값), 거절(그대로), 들여옴(「+」줄).
- 문의로 물건 바꾸기 끔: TALK_NO_STOCK, 「+」 줄 무시. 끊기 켬/끔: 잠김·REFUSED 한 번 / KICK_OFF·`<closed/>` 무시. 전부 바꿔: 산 것 유지·새 진열.
- 사기: 깎은 값·대가만·원+대가·희귀, 원 몫만 가계부에, 대가는 `paid with …`로 본편에. 잔고 부족이면 단추 막힘, 억지로 눌러도 안 삼. 다 사면 빈 진열대.
- 다음 턴 본편: 구매·대화 한 번, Recently 겹침 없음, 그다음 턴엔 사건 없고 목록만. 같은 가게 다시 열기 이어짐, 표식 없는 응답이면 비움, 다른 가게면 새 상태(옛 대화·피할 목록 안 섞임).
- 새로고침: 피할 목록에 산 7개, RESTOCK·고정 정체·지난 턴 대화까지.
- 팔기: 산 값·지난번 부른 값, 「판매」 단추·말로 수락(`<deal/>`)·안 삼(`none`)·그만. 판 사건 한 번.
- 실패: 꼴 틀림(재시도 1회 뒤 안내·원문 보기, 반쯤 저장 없음, 새로고침으로 다시 받음), 빈 답(같은 요청 다시 보내 성공), 문의 실패(내 말 되돌림·칩 되살림·다시 보내면 한 줄).
- 연타: 구매 2번 → 1번, 새로고침 2번 → 호출 1회, 보내기 2번(60ms) → 호출 1회.
- 기다리는 중 창 닫기 → 답 저장, 다시 열면 호출 없음. 가게를 떠난 뒤 늦은 답은 버림.
- 다시 굴리기(산 다음 턴): 구매·대화가 한 번 다시 실림, 돈 그대로. 산 응답 지우기: 그 구매 빠짐, 다음 응답에서 다시 삼.
- 설정 끔: 본편에서 표식 지침·대화 빠짐(산 사건은 남음), 표식 응답이 오면 지우고 비움, 다시 켜면 돌아옴. 맥락 끔·챗로그 1턴·참조 로어북 0 이 요청에 그대로. 메인 모델 선택 → `mode: model`.
- 상점 판단 = 갱신기(`$pp_on 1`): 본편에 MAIN_TAG 없음, 갱신기 요청에 상점 절·shop_check, 답대로 표식·상태, 같은 가게 이어짐, `null` 이면 비움.
- 고유 상점: 우주 쇼핑몰 `@web` → 「접속하기」, 「임직원 복지몰」 → 포인트몰 접속, 주인공(마덕희) 자기 가게 → 상점 아님.
- 페이지 새로고침: 카드·진열·대화 그대로, 호출 없음, 본편 요청이 새로 띄우기 전과 같음.
- 폰: 카드로 열기, 상세 → 구매, 아래 [문의] 서랍에서 말하기, [판매] → 서랍 판매 칩 → 「판매」, 가로 넘침 없음.
