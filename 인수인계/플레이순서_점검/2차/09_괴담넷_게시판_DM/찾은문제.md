## 문제

### 1. 선쪽지 출처 글이 같은 새로고침에서 빠지면, 모델이 쓴 선쪽지를 말없이 버림 (실제 재현)
- 누른 순서: 새로고침 → 남의 글(1846001)에 댓글 → 본편 두 턴(쉬는 턴 지남) → 새로고침. 가짜 답은 지침대로 옛 남의 글을 새 글로 바꾸고 `incoming` 에 쪽지 1통.
- 기대값: 요청에서 `incomingAllowed:true`, 출처 = 그 댓글로 쪽지를 허락했으면 받은 쪽지가 쪽지함에 들어가야 한다. 근거: 지침 `INCOMING.COMBINED`(incomingAllowed=true 면 incoming 1통 허용, 출처 = incomingOrigin), `AUTO.GUIDELINE`(「Replace unprotected NPC posts with new topics」 — 보호 안 된 남의 글은 바꾸라고 시킴), 설정 기본값 「내 댓글 있는 글 = 교체」.
- 실제값: 요청은 허락·출처를 보냈는데(`단계01_B2_선쪽지출처글_빠짐.txt` 의 COMBINED OUTPUT OPTIONS), 저장 뒤 쪽지 0통, 화면 알림도 없음, 쉬는 턴도 안 잡힘(`상태01.json`).
- 원인: `commitIncoming` 이 새로고침 결과 게시판에서 출처 글을 다시 찾는데(`src/core/gnet.ts:1052` `findPost(st, plan.post.id)`), 지침이 바꾸라고 한 그 글은 이미 빠져 있어 `return false`. `saveIncoming`(`src/ui/gnet.ts:195`)은 false 면 알림 없이 끝남. 출처 고르기는 `incomingPlan`(`gnet.ts:976~`)이 저장된 출처(`$gn_incoming_origin`)를 그대로 씀.
- 플레이어가 겪는 일: 기본 설정에서 남의 글에 댓글을 단 뒤 새로고침하면, 그 댓글 보고 오는 쪽지가 사실상 오지 않는다(모델이 그 글을 남기지 않는 한). 토큰은 쓰고 결과는 버려진다.

## 문제 아님 (확인함)
- 자동 새로고침을 기다리는 동안 그 응답을 다시 굴리면 결과가 저장됨(`branch` 10번 실패 항목). 사용자 11-11 「응답을 다시 굴려도 인터넷 자동 호출은 그대로 둔다」(`src/core/shop.ts:474` 주석)와 같은 결과. 응답을 지우면 버림(통과).
- LB.EXTRA 의 `Owner public label: null`·`Anomalies: null` 은 시험 채팅에 시작 변수가 없어서 생긴 것. 실제 시작(`src/core/start.ts:141`)·상황판 끔(`src/ui/settings.ts:225`)이 값을 채움. 변수를 넣고 다시 돌려 사라짐 확인.
- 같은 턴의 두 번째 댓글·새 글에 선쪽지가 꺼짐: 쉬는 턴 2(`HISTORY.cooldown`) 설계대로.
- 내 댓글 단 남의 글이 새로고침에 빠지면 그 댓글도 보관함에 안 남음: 설정 「내 댓글 있는 글 = 교체」 설명대로(보관함은 내 글·스크랩만, 사용자 11-10).
- 본편 요청의 게시판·쪽지 기록은 턴마다 계속 붙음: 사건이 아니라 참고 기록(관련도·최근으로 고름). 이번 턴 표시(touch)·되살린 글(back)은 그 턴만 고정되고 응답 뒤 풀림(통과).

## 통과한 흐름 (요약)
새로고침(시각·닉·최근 본문·지침·개수 자리표, 표식 안 샘) → 글 열기 → 댓글(replyTo·선쪽지·다른 글 활동 반영, 시각 보정) → 답글(parent 0 → 내 답글 아래) → 받은 쪽지 답장(원글·인용·대화 기록·역할 묶음·공개 글 참고에서 원글 본문 생략) → 글쓴이에게 쪽지 → 새 글(touch) → 본편 다음 턴(마지막 유저 앞, 사이트 이름표) → 그다음 턴 → 다시 새로고침(보호 글·주요 인물·빠진 글은 본편에서도 빠짐) → 페이지 새로고침 뒤 그대로. 갈래: 컨텍스트 끔/켬, 자동 매 턴(한 번·다시 굴려도 안 부름·다음 턴 또), 창을 열 때, 한 번에 요청(괴담넷+괴담갤 한 호출·따로 저장), 실패·빈 답·꼴 틀림 재시도·posts 빈 배열, 댓글 실패(내 댓글 남음), 쪽지 실패(지우고 입력칸 복원), 늦게 온 답(추천만 → 적용, 기다리는 동안 등록 막힘), 연타, 응답 지우면 자동 결과 버림, 선쪽지 끔, 메인 모델, 창 닫아도 저장, 스크랩 → 보관함 → 댓글로 그 턴만 되살림, 새 댓글 보기, 내 댓글 지우기(출처 번호 당김), 다양성 강화(낮은 확률 벌), 내 댓글 있는 글 유지, 괴담갤·세정게·연어 마켓 따로 저장·지침, 연어 팝니다 말머리, 네 게시판 본편 덩어리, 폰 새로고침·댓글·쪽지.
