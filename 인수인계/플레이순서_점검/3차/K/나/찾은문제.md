## 발견

### 1. [진짜 버그] 글을 친 직후 왼쪽 「거점」을 누르면 방금 고친 값이 사라진다

- 누른 순서: 세계 → 요원 → 큐라스 → 직급 칸에 「시험직급T2」 입력 → 0.7초 안에 왼쪽 「거점」 → 3초 기다림 → 「요원」 → 큐라스.
- 기대: 고친 값이 카드에 저장 (K-01 바로 저장, 사용자 결정). 페이지를 옮기는 것은 저장 취소가 아니다.
- 실제: 카드·화면 모두 「선임 요원」. 카드 쓰기 0회. 「조직」 페이지로 옮길 때는 저장된다 (B-12b). 1.5초 기다렸다 옮기면 저장된다 (T2-B2).
- 저장 실패 알림이 뜬 채 「거점」을 다녀와도 고친 값이 아무 말 없이 사라진다 (I-04). 다음 입력 때 다시 저장되리라 믿은 값이 없어진다.
- 근거: src/ui/editor/index.ts:1128 `if (edUi.node === 'base') resetDirectory();`. resetDirectory(src/ui/directory.ts:62)가 `draft: null` 로 0.7초 뒤 저장될 명부 초안을 버린다. 그 뒤 later('world') 가 돌아도 anyDirty() 가 거짓이라 쓰지 않는다.
- 재확인:
  - 재현: T1 B-12·I-04, T2 실제 리스아이 T2-B1 (before·after·돌아온 화면 모두 옛 값).
  - 설계: 「거점」 페이지를 열 때 목록 상태(kind·open·q)를 비우려는 줄인데, 초안까지 비운다. 사용자 결정 K-01(바로 저장)과 부딪힌다. 코드로 보면 직급뿐 아니라 명부 초안에 든 고침(소속·사진·연락처 탭·시작 화면 등)이 모두 같은 길을 탄다 (돌려 본 것은 직급뿐).
- 근거 파일: out/run-t2-1280x800.log, T2-B1_거점다녀온뒤-1280x800.png, out/결과_T1.json (B-12, I-04).

### 2. [진짜 버그] 직접 만든 조직을 기본 정보의 「지우기」로 지워도 남아 있다

- 누른 순서: 세계 → 조직 → 「시험조직T2」 만들기 → 소개 한 줄 → 기본 정보의 「지우기」 → 편집기를 닫았다 다시 열기 → 조직 목록 → 다음 턴 보내기.
- 기대: 목록과 다음 요청 세력 지침에서 빠짐. 단추 이름이 「지우기」다. K-19 「지운 거점·조직은 되살아나지 않는다」(사용자 결정).
- 실제: 명부 조직 줄만 빠진다. 「세계」 기록(소개)이 남아 가상 🌆세력 폴더로 목록에 그대로 보이고 (머리 「카드에만 있음」), 다음 본편 요청 📜Faction 과 관계 표에도 남는다. 머리의 「삭제」는 확인 팝업을 거쳐 제대로 지운다 (C-04b).
- 근거: src/ui/directory.ts:1116 dir-org-del 은 `d.orgs` 와 거점 org 만 바꾸고, 세계 덧쓰기(edUi.over.org)는 손대지 않는다. 확인 팝업도 없다. 거점 지우기(G-05)는 확인 팝업이 있다.
- 재확인:
  - 재현: T1 C-04, T2 실제 리스아이 T2-C1 (`dirRowAfterDel:false, record:true, listed:true, inReq:true`).
  - 설계: 기록이 없는 조직(명부 줄만 있는 조직)이면 이 단추로 지워진다. 그러나 화면에서 만든 조직은 늘 기록이 생기므로(C-01) 이 단추로는 지울 수 없다. 사용자가 「지우기」를 누르면 조직이 그대로 다시 보이고 모델에게도 계속 간다.
- 근거 파일: out/C-04_요청_조직지운뒤.txt, out/T2-C2_본편요청-1280x800.txt, T2-C1_조직지운뒤-1280x800.png.

### 3. [진짜 버그] 점검 「초기화」가 고친 명부 칸(직급 등)을 되돌리지 않는다

- 누른 순서: 세계 → 요원 → 스팡달 소개에 「시험소개H」, 직급 「시험직급H」 → 점검 → 저장·불러오기 → 「초기화」 → 확인 팝업 「초기화」.
- 기대: 도움말 「지금 채팅의 설정과 저장해 둔 기본값, 고친 지침, 고친 세계(카드 명부)를 플러그인 원래 값으로 되돌려요」. 11-08 사용자 「초기화는 전체 초기화」(src/ui/editor/index.ts:959 주석).
- 실제: 소개(세계 덧쓰기)는 비워지고, 직급(명부 칸)은 「시험직급H」 그대로. 「초기화했어요」 알림은 뜬다.

- 재확인:
  - 재현: T1 K03-03, T2 실제 리스아이 T2-H1.
  - 설계: 도움말과 사용자 말 모두 명부까지 되돌린다고 한다. 명부의 「원래 값」을 어디서 가져올지(처음 카드의 Directory)는 Claude 가 정할 거리다.

### 4. [의도] 조용한 저장 실패(silent)에는 알림이 없다

- 실제: 알림 없이 화면이 카드 옛 값으로 돌아가고, 닫을 때 묻지 않는다 (I-01·I-03-silent). 다음 입력에는 다시 저장된다 (I-02-silent).
- 실제 리스AI 에서 조용히 안 쓰는 경우는 권한 거절·캐릭터 번호 없음뿐이라, 플러그인이 알 길이 없다. throw 쪽은 알림·묻기가 제대로 된다.

### 5. [의도] 친 직후 새로고침하면 그 글자는 사라진다

- T2-F2(바로)·T2-F3(1초 뒤) 모두 앞 값 「시험직급R1」. 2초 뒤 새로고침은 남는다 (T2-F1). 코스 5장 「진행 중 작업은 메모리라 사라짐」, 리스AI 의 0.5초 저장 모음과 같다.

### 6. [의도] 그 밖

- 글이 빈 새 장면은 시작 패널에 안 나온다 (H-03, factions.ts:99).
- 성별 「미정」은 고른 값으로 남는다 (B-09). 비운 것이 아니라 고른 것이라 K-19 「비우면 다시 채움」과 다르지 않다.
- 세계 탭엔 「이 채팅 / 새 채팅 기본값」 범위 칩이 없다 (J-02). 세계는 카드 명부라 모든 채팅에 같이 간다 (J-01).

### 7. [잘못 봄] 폰 가로 넘침 판정

### 8. [잘못 봄] 미리보기와 요청 Faction 차이, AN 줄 이름

- 「세력 지침 보기」는 CBS({{#if st_faction}})를 풀기 전 글이고, 요청은 리스아이가 푼 글이다. 그 밖의 줄은 같다 (K-01 단계).
- 요청의 [AN] 줄은 표시 이름이 아니라 로어북 이름을 쓴다 (E-02). 표시 이름은 화면용.

### 9. [결정됨·안 만듦] K-19 「비우면 다시 채워지는 칸」 문장

- 거점 영문명·조직, 조직 영문명을 비워 저장하면 지금 코드는 비운 채 남긴다 (G-06·G-06b). K-19 문장은 「비워 저장하면 기본값이 다시 들어옴」인데 같은 줄에 「지금 코드로 다시 확인 안 함」이 붙어 있다. 사용자 결정은 「그대로 둔다」이므로 동작을 바꿀 일은 아니고, 결정표 문장이 지금 코드와 다르다는 알림이다.

### 10. [결정됨·안 만듦] K-03 「초기값으로」

- K-03 은 항목 되돌리기 단추 이름(「초기값으로」)과 「모두 기본값으로」 뺌을 정했다. 세계 탭에는 기록별 되돌리기 단추가 없고(K03-01), 지운 기본 기록은 「되살리기」, 전체는 점검 「초기화」다. 「모두 기본값으로」는 없다 (맞음).
