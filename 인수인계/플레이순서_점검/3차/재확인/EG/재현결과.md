- 상점 사기·팔기, 우주몰 결제, 홈쇼핑 주문, 상자 열기(던짐): 저장된 채팅은 그대로(반쯤 바뀜 없음), 다시 시도 없음, 끈 뒤 한 번만. 화면에 실패 안내 없음 — 콘솔 「[goei] 조작 실패(shop-buy|shop-sell|mall-pay|hs-order|hs-box-open): 시험용 저장 실패」만. 대본이 모은 알림 글은 픽스처 쪽 「설치 자료 목록을 받지 못했어요」뿐. 캡처로도 확인(`SP/t1-E/T1-shop-buy-throw.png`: 진열·잔고 그대로, 안내 없음). `SP/t1-E.log`.
- 소지품 사용(H t1 사본): 사용 자리 안 생김, 창 살아 있음, 안내 글 빈칸, 콘솔 「조작 실패(items-use)」. `SP/t1-H.log`, `SP/t1-H/t1-사용-저장던짐.png`.
- 생성 공통 「다시 보기」(K/다 t1-kfail 사본): 던짐이면 칸에 2 가 남고 안내 없음, 다시 열면 빈칸(저장 안 됨). 같은 대본의 기기 값(메뉴 위치, goei:prefs 던짐)은 「기본값을 저장하지 못했어요」 안내가 뜸. `SP/t1-K.log`, `SP/t1-K/out/t1-kfail-chat-throw.png`.
- 괴담톡 보내기(F 더한갈래 fail 사본): 던짐이면 페이지 오류(잡히지 않은 예외) 「시험용 저장 실패」, 화면 안내 없음, 입력칸 글은 남음, 다시 보내기는 됨. `SP/t1-F.log`, `SP/t1-F/결과-fail.json`.
- 「조용히 안 씀」은 리스AI 가 알리지 않는 길이라 성공 안내가 뜨는 것도 원래 보고와 같다(판정 밖).
- 실제 리스AI 에서 저장이 던지는 경우를 T2 로 만들지는 않았다(T1_사용법: 리스AI 996a553 setChatToIndex 는 거절·번호 없음 때 조용히 끝남).
