## 넣는 법

새 컨테이너에서 (T2 세우기는 `../T2_사용법.md` 맨 위 「새 컨테이너에서: bash t2-setup.sh」):

```js
import { openT2 } from './risu-t2.mjs';            // 틀/ 에서
import { fileURLToPath } from 'node:url';
const t = await openT2({ via: 'plain' });          // FAKE_URL 은 t2-setup.sh 가 찍은 것 (source /tmp/t2/t2-env.sh)
await t.setup();                                   // 카드·플러그인 가져오기, 모델 설정, 캐릭터 고르기 (빈 「Chat 1」 하나)
const r = await t.loadState(fileURLToPath(new URL('./states/S-관리국-3턴.json', import.meta.url)));   // 절대 경로. .pathname 은 한글이 %EC… 로 깨진다
// r = { nChats, chatPage: 0, chatId(새 id), messages, before, importedId, originalId, name }
```

조종 서버로는 `{"op":"setup"}` 다음 `{"op":"loadState","file":"<절대 경로>"}` (`select:false`·`storage:false` 도 받음).

`loadState(file, { select = true, storage = true })` 가 하는 일 (`../risu-t2.mjs`):
1. 리스AI `characters.ts importChat()` 을 부르고(채팅 목록 「가져오기」 단추와 같은 함수) 열린 파일 고르기 창에 그 파일 내용을 넣는다. (경로로 넣으면 한글 경로에서 `change` 가 안 일어나 가져오기가 안 됐다 → 내용을 버퍼로, 이름 `goei-state.json` 으로 넣는다. 2026-11-24 확인)
2. 채팅 수가 늘 때까지 기다린다(30초 넘으면 던짐).
3. `storage` 면 `t2.pluginStorage` 를 기기 저장소에 되돌린다.
4. `select` 면 `changeChatTo(0)` — 채팅 목록에서 그 채팅을 누른 것과 같은 길. 그 뒤 1.5초 쉼.

## 넣는 차례와 채팅 번호 (중요)

리스AI `importChat`(json `ver 2`, `src/ts/characters.ts:420-449`)의 동작:

- 가져온 채팅을 **맨 앞(0번)에 끼운다**(`chats.unshift`). 이미 있던 채팅은 **번호가 모두 +1 밀린다.**
- 가져온 채팅의 `chat.id` 를 **새로 만든다**(`v4()`). 파일의 `data.id` 와 다르다(`r.originalId` vs `r.chatId`). 메시지마다 붙은 `chatId` 는 그대로다.
- 고른 채팅 번호(`chatPage`)는 **바꾸지 않는다**(성공 알림만). 그래서 가져오기 전에 k번을 보고 있었으면, 가져온 뒤 k번 자리는 원래 k-1번이던 다른 채팅이다. 0번을 보고 있었으면 가져온 채팅이 화면 새로 그리기(`ReloadGUIPointer`) 없이 0번 자리에 들어선다. `loadState` 는 그래서 끝에 `changeChatTo(0)` 을 한 번 부른다.
- 여러 개를 넣으면 **마지막에 넣은 것이 0번**이다. verify 에서 여섯을 차례로 넣은 뒤 채팅 목록: 0 `S-요원플레이`, 1 `S-프리랜서-임무`, 2 `S-백일몽-3턴`, 3 `S-상점표식`, 4 `S-관리국-3턴`, 5 `S-start`, 6 `Chat 1`(setup 이 만든 빈 채팅).
- 플러그인 저장 열쇠 가운데 채팅 번호로 잡는 것이 있다(코스 5장 「다른 채팅 다녀오기」 칸). 채팅 안 상태(`scriptstate`·`goeiPeopleV1`)는 파일에 같이 들어가 번호와 상관없이 따라오지만, **상태를 넣은 뒤에 또 넣거나 새 채팅을 만들면 앞 채팅의 번호가 밀린다.** 한 구간 점검은 `setup()` → 상태 하나 `loadState` 로 시작하는 것을 권한다. 번호 밀기 자체를 보는 갈래는 이 차례를 기준으로 삼는다.
- `S-start` 를 넣는 것과 `setup()` 직후의 빈 「Chat 1」 은 같은 꼴(메시지 0, `fmIndex -1`)이다. 다만 넣은 쪽은 0번, 빈 「Chat 1」 은 1번으로 밀린다.
