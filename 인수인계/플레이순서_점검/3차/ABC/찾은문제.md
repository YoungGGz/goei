## 0. 사용자용 요약 (짧게)

고칠 것 여덟(작은 것 포함, 7·8은 2차에서 찾음), 물을 것 없음.

1. 플러그인이 옛 판이라 본체를 못 받을 때, 첫 창엔 「업데이트하라」는 말이 없고 「다시 받기」를 한 번 눌러야 나온다.
2. 생각 글을 `<thinking>` 으로 쓰는 모델이면 생각 속 상점 표식·상태창이 화면에 카드로 뜬다. `<think>` 도 생각 속 상태창이 두 번째 카드로 뜬다.
3. 괴이가 아닌 다른 봇 채팅에서도 답에 `[▣|…]` 줄이 있으면 괴이 상태창 카드로 그린다.
4. 첫 장면 표식 `%%GOEI_SCENE%%` 이 인물 기록 갱신기 요청에 섞여 간다.
5. 전송 권한을 거부한 채 기다리다 「취소」를 두 번 누르면 채팅은 비지만, 늦게 온 답이 빈 채팅에 혼자 붙고 「다시 고르기」 창이 그 위에 뜬다.
6. 처음 켤 때 권한 셋을 한 번에 물은 뒤, 2초쯤 뒤 「데이터베이스 전체 접근」 권한을 네 번째로 따로 묻는다.
7. 답이 온 뒤 첫 채팅 저장이 오류로 끝나면 그 턴 처리 전체가 빠진다(사건 반영·태그 걷기·잔고 맞추기·인물 기록 갱신). 화면엔 아무 알림이 없다.
8. 요원으로 플레이할 때 페르소나 이름이 기본값(User)이면, 본편 요청에 「User = 쟈알디」라는 연결이 없다. 지침은 User 라고만 부르고 페르소나 칸엔 「Character - Jyaldi」만 있어 모델이 쟈알디를 주인공으로 알 길이 없다.

나머지는 의도대로 돌았다(설치 창·다른 봇 설치, 받기 실패 창, 시작 표 68칸, 다시 굴리기·지우기·이어 쓰기·다른 채팅·새로고침, 자동 재시도, 라우터 시간 제한, 메인 모델 보조 호출, 2차: 조립 단계 하나 실패 12종·시작/설정/세계 저장 실패·보조 스트리밍 끊김·카드 업데이트 확인→준비→적용·옛 판 채팅 채우기·진단 화면·아이콘 되돌리기·시작 전 기본값/AI 상담·아바타/시작 잔고·요청 조립 순서·참고 기록 상한·로어북 확인 화면).
