# 13. 이미지 태그 보충

기준 코드 `b7c9264` (v0.21.32). 배포용 카드와 실제 번들, Chromium, 모의 Risu 호스트·모델을 사용했다.

보충 모델 선택, 목록 밖 이름과 표정 제거, 요청에 이미지 지침 한 번, 연속되지 않은 정상 태그 삽입을 확인했다. 첫 보충 답을 대기시킨 사이 둘째 본편 응답의 출력 이벤트를 넘기면 둘째 응답에는 보충 호출이 없었다. 같은 설정의 셋째 응답을 단독 처리하면 태그가 붙었다.

관련 단위시험 27개 통과.

### 08. 보충 처리 중 도착한 최신 응답의 이미지 태그가 누락된다

같은 인물의 c1 보충을 지연시키고 c2 출력 이벤트를 먼저 끝냈다. 보조 호출은 하나였고 c1·c2 모두 원문이었다. 늦게 온 c1의 폐기는 정상이다. 같은 설정에서 홀로 처리한 c3에는 <img=Jyaldi_smile>가 붙었다.

재검사 기준은 다음과 같다. 늦은 응답의 덮어쓰기를 막으면서 최신 응답에 남은 보충 작업을 처리한다.
