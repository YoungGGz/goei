# 11. 괴이위키

기준 코드 `b7c9264` (v0.21.32). 배포용 카드와 실제 번들, Chromium, 모의 Risu 호스트·모델을 사용했다.

검색에서 새 문서를 작성하고 형식 오류 뒤 재시도, 저장, 링크 이동, 이전 문서 참조를 켜고 끈 다시 쓰기, 본편 참조, 생성 중 두 번째 작성 잠금을 확인했다. 묶음 기본 문서와 모바일 책갈피도 검사했다. 같은 이름의 위키 문서를 넣은 포인트몰에서 관련 참조를 켜면 진열과 상담 요청에 각각 지정한 문서가 들어갔고, 끄면 두 표식이 모두 빠졌다.

관련 단위시험 38개 통과.

위 경로에서 별도 결함을 재현하지 않았다.
