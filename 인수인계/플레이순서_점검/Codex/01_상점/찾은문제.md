# 01. 상점

기준 코드 `b7c9264` (v0.21.32). 배포용 카드와 실제 번들, Chromium, 모의 Risu 호스트·모델을 사용했다.

상점 표식으로 입장해 300원과 200원 상품을 샀다. 잔고 1,000원에서 500원, 거래 두 건, 소지품 각 한 개를 확인했다. 두 상품을 다 사면 즉시 새로고침과 재입장 모두 정상이다. 일부만 샀을 때와 아무것도 사지 않았을 때는 미구매품이 제외 목록에서 빠졌다. PC·폰 결과가 같았다. 250원 판매 후 잔고 750원, 다음 턴 판매 사건 전달, 그다음 턴 중복 없음도 확인했다.

관련 단위시험 79개 통과.

### 01. 미구매품이 새 진열 요청에서 빠진다

연필만 사고 새로고침하면 제외 목록에는 연필만 있고 지우개가 다시 뜬다. 아무것도 사지 않으면 목록 자체가 없다. 두 온라인 몰에서도 유리책갈피로 같은 현상을 확인했다.

재검사 기준은 다음과 같다. 이미 진열한 미구매품을 다음 요청에 포함하고 부분 구매·미구매·전부 구매를 각각 대조한다.

근거 코드 `src/core/shop.ts:1074`.

### 02. 상점 요청의 최근 본문에 플레이어 잔고가 남는다

일반 상점 첫 요청에는 상태창 원문의 1000, 두 몰 첫 진열 요청에는 시험용 현금 73519와 포인트 1500이 남았다. 실제 모델이 가격을 달리 불렀는지는 측정하지 않았다.

재검사 기준은 다음과 같다. 잔고를 제외하는 상점 경로에서 최근 본문의 상태창 줄도 검사한다. 상담·다른 기능은 각 기능의 전달 규칙을 기준으로 판단한다.

근거 코드 `src/ui/shop.ts:351`.

### 초판 03·04 판정 정정

03의 사건 자리표는 발생 대기 브리핑이며 사용자가 유지하기로 했다. 04는 무게 구분자를 생략한 규격 밖 응답에서 나타난 현상으로, 현재 수정 요구에서 제외했다. 방금 구매한 항목이 Recently와 This turn에 함께 적히는 문구는 사용자 결정에 따른 별도의 간소화 대상이다.
