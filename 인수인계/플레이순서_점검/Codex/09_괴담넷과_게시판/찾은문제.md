# 09. 괴담넷과 게시판

기준 코드 `b7c9264` (v0.21.32). 배포용 카드와 실제 번들, Chromium, 모의 Risu 호스트·모델을 사용했다.

글 열기 → 댓글·답글 → 선쪽지·답장 → 글쓰기 → 본편 반영 → 삭제를 실행했다. 게시판에 깨진 응답·빈 응답·호출 실패를 주고 재시도를 확인했다. 글·댓글·쪽지, 발신자, 이중 클릭, 글 500개, 받은 쪽지 보관 상한과 삭제, 자동 생성 모델 통합·분리, 생성 중 변경 보존을 확인했다.

관련 단위시험 33개 통과.

위 경로에서 별도 결함을 재현하지 않았다.
