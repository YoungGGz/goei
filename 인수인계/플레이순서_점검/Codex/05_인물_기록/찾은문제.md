# 05. 인물 기록

기준 코드 `b7c9264` (v0.21.32). 배포용 카드와 실제 번들, Chromium, 모의 Risu 호스트·모델을 사용했다.

빈 기록으로 시작하면 첫 요청에 보조 호출이 없고, 첫 응답 뒤 갱신기가 돌았다. 둘째 요청에서 Router·Director와 기록 주입을 확인했다. 명단 밖 인물과 인용 없는 변경, 실패·재시도, 수동 편집·고정, 세력 평판과 되감기도 검사했다.

관련 단위시험 200개 통과.

위 경로에서 별도 결함을 재현하지 않았다.
