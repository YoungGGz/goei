# 14. 호출 흐름과 진행 창

기준 코드 `b7c9264` (v0.21.32). 배포용 카드와 실제 번들, Chromium, 모의 Risu 호스트·모델을 사용했다.

이미지 보충의 미리보기와 실제 모델 입력을 같은 채팅에서 비교했다. 역할 user, 본문 길이 3,328인 메시지 한 건이 글자까지 같았다. 관제·상담 통합 경로 551개 검사를 실행했다. PC·폰, 어두운 화면·종이 화면에서 진행 창을 열고 옮겼다. 포인트몰 1:1 상담을 켰을 때와 껐을 때 실제 몰의 상담 버튼은 각각 1개와 0개였다. 관제 화면은 두 경우 모두 보낼 때마다 1회로 표시했다.

관련 단위시험 20개 통과.
