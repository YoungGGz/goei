# 07. 본편 요청 조립

기준 코드 `b7c9264` (v0.21.32). 배포용 카드와 실제 번들, Chromium, 모의 Risu 호스트·모델을 사용했다.

첫 턴·둘째 턴·다시 굴리기, 로어·명부·상태창·소지품·이미지 지침의 위치와 설정, 한 단계 예외 후 복구를 묶어 49개 검사가 통과했다. PC·폰 호출기록에서 본편과 보정 구간을 구별하는 14개 검사도 통과했다.

관련 단위시험 59개 통과.

위 경로에서 별도 결함을 재현하지 않았다.
