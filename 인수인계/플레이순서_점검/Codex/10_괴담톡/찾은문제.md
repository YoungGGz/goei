# 10. 괴담톡

기준 코드 `b7c9264` (v0.21.32). 배포용 카드와 실제 번들, Chromium, 모의 Risu 호스트·모델을 사용했다.

1:1 발송·답장 → 선톡·단톡 초대·공지 확인 → 단톡 생성 → 전화 → 본편 반영 → 자동 확인을 실행했다. 선톡 확률 0과 대기 턴, 공지만 받기, 잘못된 답장 건너뛰기, 보내기 대기 줄, 개인 선물과 첨부, 초대로 단체방 전환, 인원 상한·퇴장·방 삭제를 검사했다. 다른 채팅의 자동 확인이 현재 방의 읽음·알림을 바꾸지 않았다.

관련 단위시험 48개 통과.

위 경로에서 별도 결함을 재현하지 않았다.
