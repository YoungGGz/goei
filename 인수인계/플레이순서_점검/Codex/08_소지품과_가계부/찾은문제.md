# 08. 소지품과 가계부

기준 코드 `b7c9264` (v0.21.32). 배포용 카드와 실제 번들, Chromium, 모의 Risu 호스트·모델을 사용했다.

PC·폰에서 다음 메시지 사용 예약, 대기 중 취소 거절, 시간 초과 뒤 예약 복원, 사용 칩의 위치와 제거를 확인했다. 가계부 수정 허용·차단, 금액 검사·되감기, 모바일 머리 잔고와 ID 카드도 확인했다. 소모·장착·초과·소실은 관련 단위시험 결과에 기록했다.
