## 문제 1 (중대) 새로고침할 때 지금 걸린(안 팔린) 물건을 「다시 내지 말 것」에 안 넣음 — 두 몰 모두

- 누른 순서
  - 우주몰: 상품 가져오기(구두약·우산·신문) → 구두약·우산 사기 → 다음 턴 → 「상품 가져오기」(새로고침).
  - 포인트몰: 상품 불러오기(응급 키트·마스크·앰플) → 키트·마스크 사기 → 몇 턴 뒤 새로고침.
- 기대값: 피할 목록에 산 것과 지금 걸린 신문(포인트몰은 앰플)이 다 들어감. 근거: 두 몰 지침 VARIETY 「Do not repeat items from the previous shelf」, 우주몰 ASSIGN_RULE 「nothing from previous shelves」, 설정 「지난 진열대 피하기」, 상점 문제 1(사용자 지적).
- 실제값: `Previously shown here (do not repeat): 반짝 걸음 구두약, 말 듣는 우산` — 신문 없음(단계09). 포인트몰도 `현장용 소형 응급 키트, 안대형 수면 마스크` 뿐, 앰플 없음(단계28). 진열 요청엔 [지금 진열대] 칸도 없음.
- 원인: 상점과 같은 함수. 피할 목록 = `prev` + 산 것(`src/core/shop.ts:1074` prevNames). 안 팔린 것은 새 진열을 받은 뒤에야 `prev` 에 들어감(`shop.ts:828` applyShelf). 쇼핑몰 진열 요청 `src/ui/malls.ts:178` 이 같은 `shelfPrompt`(SHELF_RULES)를 씀.
- 플레이어 증상: 마음에 안 들어 새로고침했는데 같은 물건이 다시 나올 수 있음. 우주몰은 칸마다 장르를 새로 굴려(`cosAssignment`) 덜하지만, 포인트몰은 분류 수가 적어 더 잘 겹칠 수 있음(빈도는 가짜 답으로 확정 못 함).

## 문제 2 (보통) 우주몰 문의가 실패하면 보낸 말과 붙인 물건이 사라짐

- 누른 순서: 「거꾸로 시계」에서 「질문 하기」 → 「시계는 몇 번 돌릴 수 있어?」 보냄 → 답이 꼴이 틀림(`<owner>` 없음, 재시도까지 실패).
- 기대값: 보낸 말이 화면에 남거나 입력칸에 돌아오고, 붙인 물건 카드도 돌아와 다시 보낼 수 있음. 근거: 기본 상점은 실패 때 보낸 말을 `failSay` 로 남기고 칩을 되돌림(`src/ui/shop.ts:478-480`, 눌러3 「실패하면 고른 물건·칩이 사라졌다」를 고친 것), 포인트몰 1:1 상담도 입력칸에 돌려줌(`src/ui/malls.ts:688-694`). 지침 4절 「응답 실패: 내 말이 남나, 다시 보낼 수 있나」.
- 실제값: 실패 안내는 뜨지만, 대화 칸에서 내 말이 지워지고 입력칸은 빈칸, 붙인 상품 카드도 없음(단계15).
- 원인: `src/ui/malls.ts:613-614` 가 보내기 전에 `v.input`·`v.chip` 을 비우고, 실패 처리 `malls.ts:226-236` 은 대화의 내 말만 지우고 입력·칩을 돌려놓지 않음.
- 플레이어 증상: 긴 질문을 쳤는데 답이 안 오면 글이 통째로 없어져 다시 쳐야 하고, 어느 물건을 물었는지도 다시 붙여야 함.

## 문제 5 (사소) 우주몰에서 산 것이 본편에 「두 번 치른」 꼴로 감, 받은 맞춤 주문은 「방금 또 삼」으로 감

- 플레이어 증상: 본편 모델이 송금 + 현금을 따로 낸 것처럼, 또는 받는 턴에 300만 원을 또 낸 것처럼 쓸 수 있음(빈도는 실제 답을 봐야 함). 잔고 계산은 맞음.

## 확인만 한 것 (문제 아님)

- 자동 호출 기본 「수동」: 두 몰 다 열어도 호출 없음, 다시 열어도 없음. 「창을 열 때」로 바꾸면 새 턴에 열 때 한 번, 같은 턴에 다시 열면 안 부름(단계19).
- 우주몰 진열: FIRST·SHELF_SECRET·진실 칸 줄 꼴·TRUTH_MIX(기본)·진열 배정(₩)·로어북 「우주 쇼핑몰」. 「진실 미리 정하기: 전부」로 바꾸면 TRUTH_ALL 절로 바뀜. 진실 `?`·글 둘 다 저장, 화면엔 광고 문구만 보이고 진실은 안 보임. 함께 온 한마디는 공지로.
- 운영자 문의: 지금 진열대 줄 끝 진실 칸 + SECRET_NOTE, INFO·ORDER 절, 붙인 물건이 마지막 줄에. 쪽지 카드는 제목·값만, 사면 소지품 「쪽지: …」에 내용. 다음 문의에 「(500000, bought)」로 넘어감.
- 맞춤 주문: 견적 카드는 이름·값·납기만. 선납 → 잔고 −3,000,000, 주문 조회 「납기 2025.03.15 02:00 AM (5시간 남음)」. 납기 지난 응답 끝에 완성 표식, 본편엔 READY 한 번(표식은 본편에 안 샘), 받으면 설명·광고 문구가 보이고 진실은 숨김, 표식 지워짐, ARRIVE_ORDER 한 번, 다음 턴 없음.
- 장바구니 → 입금: 잔고 6,500,000 → 2,800,000, 소지품에 진실째. 다음 턴 본편에 구매·ARRIVE·문의·주문 사건이 한 번씩, 그다음 턴엔 안 나오고 목록엔 남음.
- 쓰는 턴: 「사용」에 넣은 구두약은 `Really` 에 진실 + 광고 문구, 진실 `?` 인 우산은 「지금 정하라」 줄. 안 쓰는 턴엔 진실이 안 감. 다음 턴 「uses」 되풀이 없음.
- 팔기: 산 값·지금까지 산 것 줄이 요청에, 판매 단추로 잔고 +300,000, 본편에 판 사건 한 번.
- 갈래: 산 턴(c1) 다시 굴리기 → 화면 잔고 10,000,000, 진열·쪽지·견적이 다시 살 수 있게, 주문 없어짐. 구매 뒤 보낸 턴의 응답(c2) 다시 굴리기 → 다시 받는 요청에도 구매·ARRIVE·문의·주문이 한 번씩. 소지품·가계부 끔 → 「지금 영업 아님」, 새로고침해도 호출 없음.
- 관리국 소속: 브라우저에 포인트몰 없음.
- 포인트몰: 보유 포인트 표시, 9000p 상품은 「포인트 부족」 단추가 눌리지 않음, 화면 밖에서 눌러도 안 바뀜. 사면 포인트만 빠지고 원 가계부 그대로, 물건은 수령 대기. 본편엔 PICKUP_WAIT 줄(매 턴 남음), 「방금 삼」 없음. 인물 기록 끔이면 받기 → 바로 소지품 + ARRIVE 한 번. 인물 기록 켬이면 받기 → 「수령하러 감」, 본편 PICKUP_TRY 한 번(대기 줄과 안 겹침), 갱신기 답이 없으면 안 받고 다음 턴 대기 줄로 돌아옴. 산 턴 다시 굴리기 → 포인트 3,800 P, 주문 조회에서 빠짐.
- 1:1 상담: 연결 요청에 계정·남은 포인트·진열 목록, 화면엔 「상담원 NNNN」만(실명·부서 안 보임), 답 말풍선 나눔, 본편에 상담 한 번, 다음 턴 없음.

## 가짜 답의 한계

왈도체가 지켜지는지, 운영자가 진실을 흘리지 않는지, 값이 몰 등급에 맞는지, 상담원이 매뉴얼대로 신분을 숨기는지는 실제 모델 답을 봐야 함. 이번엔 보지 않았음. 갱신기가 받으러 간 장면을 「받음」으로 판단하는 길(PICKUP_TRY 뒤 성공)은 인물 기록 점검(5번)과 겹쳐 가짜 갱신기 답을 넣지 않았음 — 실패(못 받음) 쪽만 확인.
