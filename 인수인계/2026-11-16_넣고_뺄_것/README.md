### 46개 밖: v0.21.19(`d512c02`, 이미 main·릴리스됨)에 철저 대조가 찾은 것

0.21.19로 돌아가도 이건 그대로 남는다. 따로 고칠지 사용자가 정한다.
- 명부 이름 「탐미주의」가 일반 낱말이라 「탐미주의적」만 나와도 그 인물 기록이 생기고 메인 요청에 들어감. 「명부 대조」를 꺼도 못 막음.
- 「여자」 같은 짧은 호칭 기록이 「여자친구」 같은 낱말에도 끌려옴.
- 호칭이 별명 표(「사장님」 등)와 겹치면 이름 있는 인물이 「이름 모르는 인물」로 기록됨.
- 새 기능을 꺼도 갱신기·Router 지침의 예시(경비원·택시 기사, 부장 둘)가 빠진 채 감.
- 「장면 인물 유지」가 아무도 안 시켰는데 기본 켬으로 들어감.
- 상태 풍선에 테두리만 시켰는데 그림자까지 붙음.

## 6. 사용자가 정할 것 (이것부터 묻는다)

1. **되돌리는 방식.**
   - 가. 0.21.19(`d512c02`)에서 새 브랜치를 따고, 위 표의 「넣음」「고쳐서 넣음」 커밋을 오래된 순서로 하나씩 얹는다. 「고쳐서 넣음」은 얹은 직후 고친다. `f51c3ef`는 건너뛰고, `067481c`·`9e9df2e`는 결정대로. (코디네이터 추천 「셋 다 맞다고 한 것만」을 넓힌 꼴. 셋 다 맞다고 한 것만 얹으면 9b86741 같은 큰 기능이 통째로 빠지고, 뒤 커밋들이 그 위에 쌓여 있어 거의 다 충돌한다.)
   - 나. 지금 브랜치 끝에서 `f51c3ef`를 되돌리고, 뺄 부분만 되돌린 뒤 고칠 것을 고친다. 충돌이 적고 빠르다.
   - 둘 다 결과는 같다. 이 문서의 추천은 **나**(작업이 짧고 덜 틀린다). 다만 「거짓 보고한 스레드 것을 깨끗이 털고 싶다」면 가.
2. 망상홈쇼핑 택배: 몇 턴 늦게 도착 / 괴이가 직접 배달(설정 따로).
3. 포인트몰 본사: 판정을 모델에게 맡김 / 거점 별칭을 넓혀 코드로 판정 / 막지 않고 「본사에 가야 받음」만. 위치 칸이 없는 구성에서는 어떻게 할지.
4. 곁 기능 앎의 경계(`067481c`) 중 게시판 4곳·괴담톡·1:1 상담 부분을 남길지.

6. 재시도 분석 문장(`c3254c2`): 새 문장 / 원본.
