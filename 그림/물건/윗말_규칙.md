# 물건 그림 윗말 규칙

2026-11-10 사용자 결정: 「상위 카테고리·하위 카테고리 규칙을 잘 세워야 한다」. 그림이 대합·백합·꼬막처럼 세부 종류만 있어도 모델이 「조개」라고만 쓰면 그림이 나와야 한다.

## 세 단계

종류(옷·음식 등 16가지) → 윗말(조개) → 이름(대합).

## 규칙

1. **모든 그림에 윗말을 적는다.** 윗말은 사람이 뭉뚱그려 부르는 말이다(대합 → 조개, 신라면 → 라면, 타조알 → 알).
2. **윗말은 두 단계까지.** 가까운 말과 넓은 말(꼬막 → 조개, 해산물).
3. **윗말마다 대표 그림 한 장.** 이름이나 다른 이름이 그 말 그대로인 그림이 있으면 그 그림, 없으면 가장 평범한 것을 정한다.
4. **성인·신체·괴이 그림은 보통 윗말의 대표가 될 수 없다.** 그 말 그대로인 보통 그림이 있으면 도구가 그쪽으로 바꾼다.
5. **군말은 윗말로 쓰지 않는다.** 도구·세트·상자·용품·장치·물건 같은 말. 「~도구」처럼 다른 말에 붙은 것은 된다(낚시도구).
6. **찾는 순서: 이름 그대로 → 윗말의 대표 그림 → 상자.**
7. **표에 넣을 때마다 검사한다.** `python3 tools/icon_upper.py`

## 어디에 적나

| 무엇 | 파일 |
| --- | --- |
| 윗말 → 이름들 | `그림/물건/upper/종류.txt` 한 줄에 「넓은 윗말 > 가까운 윗말: 이름 이름 …」. 이름의 띄어쓰기는 `_` |
| 윗말 → 대표 그림 | `그림/물건/upper/_rep.txt` 한 줄에 「윗말: 그림 이름」. 그 말 그대로인 그림이 없거나 다른 그림을 대표로 삼을 때만 |
| 끝 낱말 → 윗말 | `그림/물건/upper/_tail.txt` 이름이 여러 낱말인 그림은 끝 낱말로 윗말을 정한다(「실험용 가운」의 가운). 끝 낱말이 이미 윗말 표의 이름·윗말이면 적지 않아도 물려받는다 |
| 윗말을 달지 않는 이름 | `그림/물건/upper/_none.txt` 하나뿐인 괴이 물건처럼 묶을 말이 없는 것 |
| 몸통 말·다른 이름·종류 고침 | `_head.txt`·`_keywords.txt`·`_kind.txt` 한 줄에 「그림 이름: 값」. 도구가 표에 넣는다 |
| 그림 표 | `그림/물건/icons.json` — 도구가 줄마다 `up` 칸(그 그림의 윗말)과 `head_rep`(윗말 → 대표 그림 파일)을 채운다 |

## 매칭기가 쓰는 것

매칭기(`src/core/iconmatch.ts`)는 윗말의 대표 그림을 `head_rep`으로 찾는다. 「조개」라고 쓰면 조개의 대표 그림 한 장이 나온다.
`up` 칸은 어느 그림이 어느 분류에 드는지 적어 둔 것으로, 아래 「분류 말은 골고루」의 무리가 된다.
윗말을 `head`(몸통 말) 칸에 넣지 않는 까닭: 넣으면 끝 글자만 같은 이름이 그 무리의 아무 그림에나 붙는다(봉지라면 → 짜왕, 이빨나무 → 묘목. 11-10에 해 보고 되돌림).

## 새 그림을 넣을 때

1. 그림 줄을 `icons.json`에 넣는다(이름·다른 이름·종류).
2. `그림/물건/upper/종류.txt`에서 맞는 윗말 줄에 이름을 적는다. 맞는 윗말이 없으면 줄을 새로 만든다.
3. `python3 tools/icon_upper.py`로 검사한다. 「윗말 없는 한 낱말 이름」「대표 없는 윗말」이 0이 되게 한다.
4. `python3 tools/icon_upper.py --apply`로 표에 넣는다.
5. `npm run build && node --test tests/itemicons.test.mjs`

## 분류 말은 그 분류 안에서 골고루 (2026-11-10 사용자, 2026-11-22 다시 짬)

물건 이름이 세부 이름이 아니라 묶음 말(과자·다과·간식)이면 그 분류의 그림 가운데 하나를 **물건마다** 뽑아 보여 준다. 한 번 정해진 그림은 그 물건(id)에 그대로 남는다. 설정 → 소지품 「분류 말은 골고루」로 끈다(끄면 한 장).

2026-11-22 사용자: 「요원증이 보관증으로 나온다 — 로직을 제대로 세우는 게 먼저고 표는 보완용」. 전에는 윗말 표 왼쪽에 적힌 분류 345개가 전부 뽑기였고, 이름이 그림 이름 그대로(권총·담배)여도 같은 분류의 다른 그림이 뽑혔다.

### 차례 (매칭기 `makeIconIndex` 맨 끝)

1. **이름이 어느 그림의 이름 그대로면 그 그림.** 권총 → 권총. 그 이름이 「골고루 뽑는 분류」(과자)일 때만 자기 그림과 그 분류 그림 가운데 뽑는다.
2. **이름이 분류 말·같은 뜻 말이면**: 골고루 뽑는 분류면 뽑고, 아니면 그 분류의 대표 그림 한 장(나이프 → 칼, 요원증 → 사원증).
3. **그림 칸의 물건말만 분류 말이면**: 이름으로 찾은 그림 → 그 분류 안에서 이름과 같은 낱말이 든 그림(관리국 요원증 → 관리국 사원증) → 골고루 뽑는 분류면 뽑기, 아니면 대표 한 장.
4. 그림 칸의 말이 대분류(장치·기기·부적 = 그 종류 전부)면 뽑지 않는다. 대분류는 이름이 그 말일 때만 뽑는다(먹을 것·의류).
5. 이름의 끝 두 낱말 이상이 그림 이름 그대로면 그 그림(할아버지 유품 상자 → 유품 상자). 이름의 낱말을 다 가진 그림이 따로 있으면 그쪽.

### 보완 표

| 무엇 | 파일 |
| --- | --- |
| 골고루 뽑는 분류 | `upper/_draw.txt` → `up_draw`. 그 말만으로는 물건 하나로 정해지지 않는 묶음 말만(과자·음료·옷·무기·공구). 권총·담배·우유·빵처럼 물건 하나가 떠오르는 말은 적지 않는다 |
| 같은 뜻 말 가운데 물건 하나인 말 | `upper/_same_one.txt` → `up_one`. 골고루 뽑는 분류의 말이어도 대표 한 장(위스키·자켓) |
| 그 분류에 넣지 않는 그림 | `upper/_out.txt` 「분류: 이름, 이름」. 그 분류 말로 불렀을 때 나오면 어긋나는 그림(가구의 구속 의자, TV 의 셋톱박스). 도구가 `up` 칸에서 뺀다 |
| 같은 뜻 말로 쓰지 않는 말 | `upper/_same_out.txt`. 뜻이 다르거나 그 말 그대로인 그림이 따로 있는 말. 그림이 따로 있으면 `_keywords.txt` 에 그 그림의 다른 이름으로 적는다(로사리오 → 묵주). 끝말이 다른 물건의 몸통이 되는 겹말은 다른 이름으로 넣지 않는다(실내화주머니 → 「주머니」가 가방으로 간다) |
| 분류마다 같은 뜻 말 | `upper/_same.txt` 「분류: 말 말 …」, 대분류는 `@food`. 아래쪽 「영어」 칸에 영어 말(단수). 복수형은 매칭기가 단수로 바꾼다 |

- 분류로 치는 윗말은 윗말 표·끝 낱말 표의 왼쪽에 적은 것(`up_cats`).
- 종류를 성인·신체·괴이로 적지 않았으면 그 종류 그림은 무리에서 뺀다(성인용품처럼 그 그림이 대부분인 분류는 그대로).
- 같은 말이 어느 그림의 이름·다른 이름이면 그 그림이 먼저라 도구가 뺀다. 매칭기가 이미 그림을 찾아 주는 말은 `node tools/icon_same_check.mjs`가 `_same_skip.txt`에 적어 뺀다.
- 성인·신체 그림의 영어 이름은 `head` 칸에 있다(`_head.txt`로 덧붙임). 매칭기가 그 말 그대로일 때 종류와 상관없이 그 그림으로 찾는다.
- 고친 뒤: `python3 tools/icon_upper.py --apply && node tools/icon_same_check.mjs && python3 tools/icon_upper.py --apply`, 그다음 `npm run build && node --test tests/itemicons.test.mjs`
